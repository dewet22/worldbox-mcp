# Code of Conduct

This project adopts the **Contributor Covenant**, version 2.1, as its code of conduct.

The full text is published and maintained by the Contributor Covenant project at:

<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>

By participating in this project — as a contributor, maintainer, issue reporter, or any other capacity — you agree to abide by its terms.

## Reporting

To report a concern, contact the maintainers via the dedicated security/conduct channel listed in [SECURITY.md](SECURITY.md). Reports are handled confidentially.
